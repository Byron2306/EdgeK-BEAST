# BEAST IDE 3.1.0-rc3 — BLACKGLASS

Released: 2026-07-14

This release candidate completes the twelve-phase reconstruction of the BEAST renderer.

## Highlights

- One page outlet, one context rail, one mascot controller, and one production application owner.
- Twenty-two operational routes covering the editor, governance, evidence, agentic runtime, utility plane, and release systems.
- Governed terminal, SourcePlan lifecycle, models, agents, review, evidence, trust, memory, mission map, crystallization, tooling, diagnostics, providers, worktrees, deployment, Chronicle, and Compute Economy.
- Premium black-chrome and neon-green visual system with Matrix rain, moving grids, adaptive Canvas telemetry, high-definition PNG frames, repaired cursors, and normalized mascot animation.
- Orbitron, Oxanium, Chakra Petch, Rajdhani, Share Tech Mono, and related hacker-style web typography with technical local fallbacks.
- Responsive and accessibility layer with operator text scaling, contrast, reduced motion, adaptive effects, keyboard navigation, ARIA repair, and focus preservation.
- Central runtime contract with deduplicated requests, bounded retries, cancellation, stale-render protection, page-session restoration, and a runtime watchdog.
- Release diagnostics and frozen file/asset manifests.

## Important acceptance boundary

Static validation is complete. Live Electron preload, gateway mutations, Monaco, terminal streaming, provider actions, worktree operations, and SourcePlan apply must be accepted inside the actual BEAST desktop runtime using the supplied matrix and checklist.
