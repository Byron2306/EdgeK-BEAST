# BEAST C4-X: Ultimate Deterministic Intelligence Gauntlet

## Purpose

C4-X tests one bounded but consequential claim:

> BEAST can compile verified operational facts, causal rules, policies, and temporal evidence into a canonical proof graph before independently producing a structured text explanation and deterministic visual artifact, then bind both exact artifacts into one joined receipt without a provider call.

The gauntlet is deliberately adversarial. A pass requires more than matching digests. Text must be re-renderable from a structured proof-bound frame, SVG bytes must be re-renderable from a proof-bound scene plan, stale evidence may not sound current, missing causal rules may not be promoted into rule-proven claims, layout failure may not be reported as a successful render, and residual workers may not broaden their authority.

## Proof order

```text
verified facts + rules + policies + temporal evidence
                       ↓
              canonical proof graph
                    ↙     ↘
      structured text frame   deterministic scene plan
                 ↓                  ↓
      exact JSON answer bytes   exact SVG artifact bytes
                    ↘            ↙
                 joined verification receipt
```

The text realizer never reads the SVG or scene plan. The scene compiler never reads the rendered prose. Both reference the same proof claims.

## Frozen scenarios

1. Restart-risk composition with a dependency/risk diagram.
2. Traffic-shift composition with capacity and status visualization.
3. Deployment-safety composition with rollout gates and rollback path.
4. Missing restart causal rule, producing only a causal-fields residual packet.
5. Missing visual asset metadata, preserving the text answer and rendering an explicit unsupported placeholder.
6. Layout overflow, preserving proof and text while refusing visual rendering.
7. Stale restart-health evidence, blocking a current safety claim.
8. Held-out renamed services, proving the restart family is not BEAST/Commons-name-specific.
9. Metamorphic traffic-capacity mutation from safe to unsafe.
10. Failed deployment health gate, producing a deterministic halt-or-rollback conclusion.
11. Missing dependency edge, refusing restart causality.
12. Stale traffic capacity, blocking a current traffic-shift claim.

Additional attacks mutate exact text bytes, mutate exact SVG bytes, inject forbidden fields into a causal residual, attempt a full-scene escape through a visual residual, and exceed the residual byte ceiling.

A joined receipt can verify while its status is `partial`. This is intentional. Verification means the receipt accurately binds and characterizes the result. It does not falsely convert a refusal, stale conclusion, missing asset, or layout failure into a fully composed answer.

## Run

From the BEAST repository root:

```bash
python scripts/run_deterministic_intelligence_gauntlet.py
PYTHONPATH=. pytest -q tests/test_deterministic_intelligence_gauntlet.py
```

Evidence is written under:

```text
evidence/deterministic-intelligence-ultimate-gauntlet/<run-id>/
```

Each case contains:

- `proof_graph.json`
- `text_frame.json`
- `scene_plan.json`
- `answer.json`
- `diagram.svg` when rendering is valid or an explicit placeholder is allowed
- `joined_receipt.json`
- `case.json`

The run directory also contains `ultimate_gauntlet.json`, `ultimate_gauntlet.md`, and a self-excluding `SHA256SUMS.txt` manifest.

## Scientific claim boundary

This is not proof of unrestricted general intelligence, universal matrixless generation, or arbitrary open-domain reasoning. It is evidence of a bounded deterministic intelligence architecture across three operational families. Within those bounds, BEAST composes previously unmaterialized conclusions from verified capabilities, expresses one proof through two independently derived modalities, preserves uncertainty and partial validity, and refuses unsupported work without asking a provider to recreate the whole answer or image.
