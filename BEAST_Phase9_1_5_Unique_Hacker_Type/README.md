# BEAST Phase 8 — Utility and Orchestration Plane

Phase 8 completes the Providers, System, Settings, Worktrees, Deploy, Chronicle, Compute Economy, and BEAST Studio utility surfaces on Core Shell v2.

## Launch

Use `index.html` through the existing BEAST Electron renderer. For seeded visual inspection without the gateway, use `?capture=1&page=studio` and replace `studio` with any Phase 8 route.

## Installation

- Use the **full archive** for isolated testing.
- Use the **patch archive** only over a clean Phase 7.1 renderer.
- Fully restart Electron after applying the patch.

See `PHASE8_IMPLEMENTATION.md`, `PHASE8_RUNTIME_TEST_CHECKLIST.md`, and `PHASE8_VALIDATION.json`.
