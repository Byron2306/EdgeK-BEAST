## Stop rule

A prior work defeats a candidate priority sentence only if one publicly documented system contains every mechanism named in that exact sentence.

A component precedent defeats priority for that component even when it does not defeat the full conjunction.

If a full-stack predecessor is found:

- the technical BDI result remains valid;
- the broad priority claim is withdrawn;
- the claim narrows to a mechanism, protocol, independently reproduced implementation, expression-closure property, mixed-domain convergence, current-world/loss binding or authority non-escalation invariant actually absent from the predecessor.

No historical-priority sentence is released while any Tier-1 source remains only abstract-reviewed, while the Sophia→BEAST evidence edge remains unclosed, or while independent novelty review is missing.
