# DAI-Diode novelty review status

**Status:** source-backed second pass in progress  
**World-first gate:** withheld  
**Technical-validity gate:** evaluated separately from historical priority  
**Last matrix expansion:** 2026-08-04

## Current conclusion

The second primary-source pass still has not identified one public system that matches the complete DAI-Diode conjunction.

It has, however, materially narrowed the claim. 2026 produced several direct near-neighbours that occupy authority and execution territory that was previously represented only by older trust-management, provenance, and confidential-computing systems.

The matrix now contains five dangerous precursor clusters:

1. **Distributed authorization and logical trust** — KeyNote, Binder, Delegation Logic, SecPAL, DKAL/DKAL*, and SAFE establish deterministic logic over authenticated statements, credentials, delegation, revocation, multiple principals, linked contexts, and federated domains.
2. **Confidential multiparty governance and transparent receipts** — CCF and SCITT establish hardware-backed integrity, auditable ledgers, signed statements, offline-verifiable receipts, replicated state, and multiparty governance.
3. **Semantic validator quorum** — Semantic Quorum Assurance establishes declarative execution contracts, cryptographic evidence chains, diverse read-only validators, risk-adaptive quorum, vetoes, and a sovereign execution gate.
4. **Proof-derived agent authorization and certified execution** — Verifiable Agentic Infrastructure/DTF, Proof of Execution, and No Certificate, No Execution establish that model generation is not permission; authority can be derived from structured proof or certified traces, and planning, enforcement, effects, and recordkeeping should remain separate.
5. **Attested agent identity, delegated scope, and kernel mediation** — Grimlock, AURORA, ACAP, RATS/EAR, SPIFFE/SPIRE, Keylime, and Tetragon establish strong component precedents for attested runtime identity, short-lived delegated authority, eBPF mediation, kernel observation, and relying-party appraisal.

These systems defeat broad claims such as:

- first deterministic trust reasoning;
- first signed proposition or execution provenance;
- first distributed authorization logic;
- first proof-carrying or certified agent execution;
- first separation of generation from permission;
- first proof-derived execution authority;
- first attested agent or workload identity;
- first eBPF-mediated agent channel;
- first confidential multiparty governance;
- first semantic validator quorum;
- first replayable governed execution certificate.

They do **not**, on the primary sources reviewed so far, establish the complete DAI-Diode architecture in one publicly reproducible implementation.

## What changed in the second pass

The earlier candidate sentence leaned too heavily on authority separation. That is no longer safe as a primary novelty axis.

DTF already describes justification proofs, independent consensus, ephemeral execution identities, and append-only evidence chains. Proof of Execution separates planning, enforcement, effect, and recordkeeping. The Proposal–Certification–Execution architecture explicitly states that generation is not permission. Grimlock combines eBPF mediation, attested channels, and scope-bound tokens.

Therefore DAI-Diode must not claim priority merely for:

- proof before execution;
- separate execution gates;
- bounded delegation;
- append-only execution evidence;
- attested runtime identity;
- semantic or multi-validator quorum;
- enforcement-plane separation.

The surviving novelty target must be the **specific conjunction and mechanism chain**.

## Strong candidate claims under review

### Candidate A — bounded deterministic intelligence

> **DAI-Diode validates bounded deterministic intelligence as an engineering architecture: closed-world deterministic composition of admitted multi-domain capabilities into new supported answers or principled refusals, with complete proposition provenance and text/visual expression derived from one authority-bounded semantic object.**

This is primarily a technical-validity claim. It does not depend on historical priority.

Its closest precursors are deterministic authorization logics, proof-carrying plans, provenance systems, neuro-symbolic composition, and graph-to-expression systems. The present search has not yet found one prior implementation combining all of:

- multi-domain learned-capability promotion;
- deterministic composition into previously unmaterialized answers;
- explicit unsupported-gap refusal;
- complete proposition-level provenance;
- one semantic object independently projected into bounded text and visual artifacts;
- exact expression tamper closure.

### Candidate B — constitutional topology

> **To our knowledge, DAI-Diode is the first publicly reproducible intelligence operating architecture in which reusable deterministic semantic capabilities are promoted only after transfer testing and adversarial challenge; transported as sealed proof-carrying objects whose custody does not convey authority; admitted only against explicit kernel-observed current-world state and observation-loss evidence; certified by a role-diverse heterogeneous attested Commons quorum; and permitted to execute through a separately attested authority path in which successful execution evidence cannot directly modify production authority.**

This is the stronger priority candidate, but also the harder one to prove.

Every clause must remain necessary:

1. **Reusable deterministic semantic capability promotion** — not ordinary code, policy credentials, cached responses, or static certified plans.
2. **Transfer testing before reusable authority** — receiver-side reproduction and applicability proof, not signature or retrieval alone.
3. **Standing adversarial challenge** — negative, deception, mutation, and stale-world cases are part of promotion and continued trust.
4. **Sealed proof-carrying custody** — memfd/descriptor transport with receiver revalidation, while possession remains non-authoritative.
5. **Current-world and loss binding** — topology, policy, boot/runtime identity, leases, resources, negative conditions, and explicit sensor loss determine applicability.
6. **Role-diverse heterogeneous attested quorum** — exact proposition/evidence/world/epoch/capability binding across independently controlled witnesses.
7. **Separately attested physical execution** — appraisal and exact one-use authority are distinct from evidence and quorum.
8. **Execution-to-production diode** — successful execution and postconditions may support claims but cannot directly mint or widen production authority.

Removing any clause risks collapsing the claim into existing work.

## Matrix interpretation

The CSV uses:

- `PRESENT` — explicitly supported by the cited primary source;
- `PARTIAL` — adjacent, configurable, or analogous, but not the same intrinsic mechanism;
- `ABSENT` — not found as part of the documented architecture reviewed;
- `UNKNOWN` — source review remains incomplete;
- `PENDING` — DAI-Diode target feature awaits final independent evidence.

`ABSENT` is always provisional. It means “not found in the reviewed primary source,” not proof that no implementation, later version, patent, thesis, or unpublished deployment contains the feature.

A `TIER_1` system is dangerous enough that its full paper, implementation, appendices, later versions, citations, and related patents must be reviewed before priority wording is released.

## Stop rule

A prior work defeats a candidate priority sentence only if one publicly documented system contains every mechanism named in that exact sentence.

A component precedent defeats priority for that component, even when it does not defeat the full conjunction.

If a full-stack predecessor is found:

- the technical BDI result remains valid;
- the broad priority claim is withdrawn;
- the claim narrows to a specific mechanism, protocol, independently reproduced implementation, expression-closure property, current-world/loss binding, or authority non-escalation invariant actually absent from the predecessor.

No historical-priority sentence is released while any Tier-1 source remains only abstract-reviewed or while independent review is missing.
