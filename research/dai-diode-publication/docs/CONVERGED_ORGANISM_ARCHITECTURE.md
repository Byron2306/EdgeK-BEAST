## 2. Evidence that the convergence is more than branding

### 2.1 Sophia and Arda coexist inside Integritas Mechanicus

Integritas Mechanicus contains both pedagogical and attestation code under the same `arda_os` runtime.

The Sophia pedagogy orchestrator performs deterministic, inspectable selection among supervisor, peer-reviewer, methodologist, source-librarian, integrity-auditor, writing-coach, examiner, novice-scaffold, and expert-challenge offices. It binds learner level, desired depth, assessment layer, scaffold intensity, Bloom/Barrett/Facione targets, reflective and ipsative state, and an explicit authorship boundary into a visible plan.

The similarity guard reports **similarity risk rather than plagiarism guilt**. It distinguishes exact overlap, near paraphrase, citation-needed overlap, shared terminology, and protected common phrases, then returns bounded repair options such as citation, quotation, attributed paraphrase, narrowing, limitation, or converting an assertion to a question.

The strict ARDA verifier independently checks evidence shape, issuer, environment, audience, nonce, evidence mode, attestation key, PCR bank and selection, workload/configuration digest, secure boot, freshness, PCR baselines, evidence signature, TPM quote, event log, and replay state. It emits a signed appraisal result with explicit hard failures and warnings.

This is already an unusual internal merger:

```text
pedagogical assistance and assessment
+ academic authorship/integrity governance
+ cryptographic and hardware attestation
+ deterministic fail-closed appraisal
```

### 2.2 Seraph and Metatron are not a single detection module

The Metatron repository contains distinct implemented organs for:

- harmonic timing analysis and scoped behavioral baselines;
- cadence, jitter, drift, burstiness, entropy, sequence tempo, resonance, discord, and confidence;
- governed deception modes and independent-corroboration requirements;
- agent behavior and threat classification;
- world entities, campaigns, mind graphs, governance epochs, world-state hashes, expression plans, and strictness state;
- signed/hash-chained event and action telemetry;
- policy decisions, capability tokens, evidence references, execution IDs, and trace/span linkage;
- BPF LSM and Valinor/Gurthang enforcement surfaces;
- outbound consequential-action gates, notation tokens, Triune/Choir appraisal, recovery, and governed dispatch;
- SOAR, threat correlation, sandboxing, network/endpoint agents, deception, threat intelligence, and forensic integrations.

Metatron therefore supplies both a cybersecurity platform and a constitutional adversarial/governance organ.

### 2.3 BEAST contains an explicit ARDA–Metatron execution bridge

`app/kernel/integration/arda_metatron_bridge.py` implements a fail-closed chain:

```text
BEAST crystal request
  -> ARDA signed appraisal and one-use authority
  -> Metatron signed appraisal and one-use authority
  -> bounded executor

```

The live bridge requires configured endpoints, verification keys, audience, policy generation, appraisal references, and a protected one-use capability ledger. The request digest must match the signed decision and appraisal. ARDA must allow before Metatron is called; both must allow before execution.

The integration assessment separately states the constitutional ownership boundaries:

- BEAST owns intent, source/change/job authority, deterministic composition, and the upstream capability lease;
- ARDA owns measured node, boot, workload, and runtime evidence plus independent appraisal;
- Metatron owns consequential-edge admission and cannot mint its own prerequisite authority;
- Seraph behavioral confidence cannot override failed cryptographic or policy vetoes;
- Sensorium and native ledgers observe effects without becoming authority.

The repository evidence presently establishes:
