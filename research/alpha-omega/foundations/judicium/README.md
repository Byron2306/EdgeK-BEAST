# JUDICIUM v0.1
Offline exploratory statistical tribunal. Run `python3 -m unittest -v` or `python3 judicium.py input.json`. Input contains schedule (task, cluster), rows (task, cluster, lane: control/beast, success: boolean, cost_micros: nonnegative integer), optional protocol keyword arguments. Costs must already include allocated acquisition and all failed attempts; no authentication or reconciliation is performed. Each task must have exactly one row per lane. Cluster bootstrap resamples entire matched clusters with replacement; percentile intervals are nominal 95%, not calibrated guarantees. Defaults: 30 clusters minimum, 2 percentage point noninferiority margin, 20% cost-per-success saving, 10000 draws. Undefined bootstrap ratios prevent positive verdicts. Threshold verdicts are exploratory, never scientific authorization. Degenerate bootstrap distributions can underestimate uncertainty (especially all-success data); do not use as confirmatory inference. Cluster independence, sample size/power, multiplicity, preregistration, missingness and independent evidence admission require further work. No provider calls. Standard library only.
