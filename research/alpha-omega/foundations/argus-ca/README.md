# ARGUS VERITAS / CAECUS v0.1
Offline primitives: Ed25519 signed, role-bound, campaign-bound sequential receipts; externally supplied expected count/head; salted commitments to exact JSON expected outputs and public input identity. No private keys or hidden answers are shipped. Generate keys under independent observer custody; pin registry and checkpoint outside the agent. Keep secret case records outside agent mounts; only disclose pass/fail after final submission. This library does not implement process isolation, durable ledger integration, key revocation, external checkpoint witnessing, network metering, billing, arbitrary code testing or statistical adjudication. Signatures authenticate assertions, not their truth. JSON canonicalization is Python-specific, not RFC 8785. No paid execution.
Requires Python 3 and cryptography (tested 46.0.4). Run `python3 -m unittest -v`.
