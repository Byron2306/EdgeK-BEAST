# PECUNIA UMBRA v0.1
Offline Python standard-library prototype. Run `python3 -m unittest -v`.
`account(schedule, events, outcomes)` accepts ordered unique string task IDs, paired boolean outcomes and unique charge events (see tests). Amounts are integer USD micros. Actual and shadow are separate ledgers; shadow is a separately supplied modeled total, not automatically added to cash. Upfront costs use task=None. Failed tasks retain costs. Ratios are exact rational strings in micros. Break-even is an observed sustained equal-success prefix, not a forecast. `allocate` conserves shared costs across weights; allocation is optional and not automatically joined to the ledger. `depreciation` returns an exact rational modeled allocation. Do not record both a parent charge and its allocations. No billing authentication, completeness proof, live provider access, automatic resource pricing, or scientific authorization. Inputs are trusted offline fixtures. No integration with other foundation packages yet.
