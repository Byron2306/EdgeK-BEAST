# ARGUS GENESIS v0.1
Offline simulated expenditure reservation ledger. Python standard library only.
Run `python3 -m unittest -v` from this directory.
Amounts are integer USD micros. Each request attempt has a unique ID. Reserve before dispatch; dispatched reservations remain held across restart until settled. Cancel only before dispatch. Actual settlement may exceed reservation: record the overrun and refuse further reservations rather than hide the cost. SQLite BEGIN IMMEDIATE serializes writers. Hash-chain replay validates state on each operation.
No provider access, credentials, gateway, invoice authentication, real spending authorization, or integration with tribunal.py. Caller supplies simulated settlement amounts; these are not billing evidence. The hash chain is not an external signature or protection against complete database rewriting/truncation. No hard real-world spending guarantee: provider-side charges can exceed estimates. Production needs independent custody, authenticated settlement, external head anchoring, provider-specific conservative price bounds, egress enforcement and fault-injection tests. This prototype uses full replay per transaction and is not optimized for large campaigns.
