# ALPHA ET OMEGA — foundation 0.1
Offline prototype only. No provider requests, native integration, signatures, hidden-test isolation or spending authority. Run `python3 -m unittest -v` in this directory. ALPHA commits canonical protocol and schedule digests; OMEGA checks schedule completeness, duplicate identities, binding and nonnegative accounting, and reports descriptive totals. Inputs are JSON arrays of schedule rows (id, lane, task, lineage, provider, model) and receipts extending those rows with verified (boolean), cash_micros, shadow_micros, calls (nonnegative integers). These are untrusted assertions, not independent evidence. `python3 tribunal.py alpha constitution.json schedule.json > commitment.json`; `python3 tribunal.py omega constitution.json schedule.json --commit commitment.json --receipts receipts.json`. OMEGA always withholds scientific verdict. Next: signed observer receipts, isolated hidden verifier, provider billing reconciliation, atomic budget reservations, preregistered lineage-level inference, full acquisition and failure accounting, external witness and native integration. No threshold is final. Do not use this prototype to authorize execution.
